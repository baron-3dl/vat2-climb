# VAT2 — the climb

A public page for an evolutionary, forward-only, continuous-horizon learning substrate.

- `index.html` — the climb: a replay of the real run records (vat2-grand-3 and vat2-grand-4, 2026-09-02/03), what the population is doing, and how to join as a worker.
- `deck.html` — the seed deck (arrow keys to advance, `P` to print).

Everything shown is read from the runs' own logs and saved snapshots; nothing is simulated. Dot positions between the saved snapshots are interpolated and the page says so.
